RUDE BREAKER 30th AE - PC版移植 - 取扱説明書
=============================================

バージョン 0.10.0 - 2026年11月3日

プログラムも同じ番号を表示します：rudebreaker --version、ウィンドウの
タイトル、CONFIG ページの一番上の行（VER 0.10.0）。

ほかの言語：英語（MANUAL.md / .txt）、ポルトガル語（MANUAL.pt-BR.md / .txt）。


1. 概要
-------

本作は、コンパイルがNEC PC-98向けに制作した縦スクロールシューティング
「ルードブレイカー（Rude Breaker）」（ディスクステーション、1996年）の
PC（Windows・Linux）移植版です。

Rude Breaker 30th AE（30th Anniversary Edition、30周年記念エディション）は、
1996年4月5日にディスクステーション Vol.10 で発表されてから30年を記念する
ものです。ゲーム本編はそのままに、次の要素を追加しています：

  - SPEEDボタン：プレイ中に自機の速度を切り替えます。上部のバーに
    SPD表示が出ます（3章）。
  - RANK：ザナック風のランクシステム。初期設定はON（4章・6章）。
  - MODERNパレットが初期設定になりました（ORIGINALも選べます）。
  - プレイ中の武器切り替え（SHIP SELECT OFF）が初期設定になりました
    （4章）。
  - Escでのポーズはプレイ中のみ。タイトルやメニューではポーズしません。
  - 最終ボスの誘導弾の軌跡スプライトが、オリジナルと同じく飛ぶ方向を
    向くようになりました。
  - 30th AEのマークとShmupsBR 2026のクレジットを入れた新しいタイトル
    画面。

この移植はリメイクではありません。オリジナルのデータファイルから、
オリジナルのゲームスクリプトとロジックをそのまま動かしています。敵の
攻撃パターン、スコア、ボスの耐久力、難易度はすべてオリジナルのコード
どおりです。音楽はオリジナルのFPLAYドライバーを、本作が想定していた
PC-98のFM音源チップYM2203のエミュレーション（ymfm）で鳴らしています。

PC側では、ウィンドウ、サウンド出力、キーボードとゲームパッド、
フレームの進行、CONFIGメニューの各種オプションを扱います。

重要：ゲームデータ（SGM1.DAT、SONG.DAT、FPLAY.COM）は著作物です。公開版の
移植には含まれておらず、再配布はできません。ご自身が正規に入手した
ゲームのものを使ってください（2章）。これらを含む非公開のテスト版は、
そのテスターだけのものです。共有しないでください。


2. インストール・起動・ゲームファイル
-------------------------------------

フォルダを好きな場所に展開してください。インストールは不要です。

  Windows：rudebreaker.exe を実行します。
  Linux：  そのフォルダでターミナルから chmod +x rudebreaker を実行し、
           続けて ./rudebreaker を実行します。
  Raspberry Pi：Linuxと同じです。この章の最後の「Raspberry Pi」を
           参照してください。

移植版のファイル：

  rudebreaker.exe       ゲーム本体（Windows）。
  SDL2.dll              ウィンドウ・サウンド・ゲームパッド用ライブラリ
                        （Windows）。
  rudebreaker           ゲーム本体（Linux x86_64）。
  libSDL2-2.0.so.0      同じライブラリ（Linux）。
  LICENSE-ymfm.txt      音源エミュレーターymfmのライセンス。
  LICENSE-SDL2.txt      SDL2ライブラリのライセンス。
  MANUAL.txt / .md      説明書。

ゲームファイル

移植版自体にはゲームデータが入っていません。お手持ちの
ルードブレイカー（ディスクステーション Vol.10、PC-98）から読み込みます：

  SGM1.DAT     必須   ステージ、スプライト、スクリプト、ゲームプログラム。
  FPLAY.COM    必須   オリジナルの音楽ドライバー。
  SONG.DAT     必須   音楽と効果音のデータ。
  RBRANK.DAT   任意   オリジナルのハイスコア・設定ファイル。

ディスクには SGC.COM、READJS.COM、RUDEBR.BAT もありますが、これらは
読み込まず、必要ありません。BIOS、フォントROM、音源ROMも不要です。
音楽はYM2203のエミュレーションで鳴らしており、ROMを必要としません。

ファイルの用意のしかたは2通りあります：

  1. ファイルをそのまま置く。SGM1.DAT、FPLAY.COM、SONG.DAT（以前の
     スコアを使いたい場合はRBRANK.DATも）を、ゲームのフォルダ（プログラム
     と同じ場所）か、その中の RUDEBR というサブフォルダにコピーします：

       Rude Breaker PC/
         rudebreaker.exe
         SDL2.dll
         SGM1.DAT
         FPLAY.COM
         SONG.DAT

     Linuxではファイル名を大文字で正確に一致させてください
     （sgm1.dat ではなく SGM1.DAT）。

  2. ディスクイメージを置く。ゲームのPC-98ディスクイメージを、そのまま
     ゲームのフォルダ（またはRUDEBRサブフォルダ）に置きます。対応形式：
     .hdm、.fdi、.d88、.hdi、.nhd、またはそれらを1つ収めた .zip。
     イメージ内のFATファイルシステムから直接読み込み、イメージ内の
     RUDEBRフォルダにも対応しています。ディスクへの展開は行いません。
     イメージが複数ある場合は、.hdm、.zip、.fdi、.d88、.hdi、.nhd の順に
     調べ、ファイルが揃っている最初のものを使います。

検索する場所と順番は次のとおりです。1と2で指定したフォルダや
イメージは、ファイルがなくても必ず使われます（その場合は下記の
ウィンドウが出ます）。3～5はファイルがある場合だけ使われ、どこにも
ない場合はプログラムのあるフォルダが表示されます：

  1. プログラムの引数で指定したフォルダまたはディスクイメージ。
     例：rudebreaker.exe D:\games\rudebr.hdm
  2. 環境変数 RUDEBR_ASSETS で指定したフォルダまたはイメージ。
  3. プログラムのあるフォルダ（まずファイル、次にディスクイメージ）。
  4. プログラムのあるフォルダ内の RUDEBR サブフォルダ。
  5. カレントフォルダの assets/raw/RUDEBR（開発者向け）。

必須ファイルが足りない場合、ゲームは起動しません。「disk files needed」
というウィンドウに、調べたフォルダまたはイメージと、各ファイルが
見つかったか（found）見つからないか（MISSING）が表示されます。足りない
ファイルを用意して、もう一度起動してください。RBRANK.DATだけがない
場合は、オリジナルのハイスコア表と初期設定で始まり、保存時にファイルが
作られます。

ゲームが作るファイル：

  RBRANK.DAT       オリジナルのセーブファイル：ハイスコア表とゲーム設定
                   （難易度とGAMEPLAYの各オプション）。ゲームファイルを
                   読み込んだフォルダ（ディスクイメージの場合はイメージと
                   同じフォルダ）に保存されます。削除するとスコアと設定が
                   初期化されます。
  rudebreaker.cfg  PC側の設定：パレット、ランク、トレーニング、キーと
                   パッドの割り当て。プログラムと同じフォルダに保存。
  rudebreaker.ini  フレーム進行の選択：pacing=smooth または pacing=exact。
  pace.txt         タイミングの簡単なレポート（7章）。削除しても
                   問題ありません。


Raspberry Pi

Raspberry Pi用のパッケージは64ビット版 Raspberry Pi OS 用です：

  RudeBreaker-RaspberryPi-*.zip    64ビット版 Raspberry Pi OS
                                   （aarch64）。Pi 3、Pi 4、Pi 5、
                                   Pi Zero 2 W。

OSの確認は、ターミナルで次を実行します：

  uname -m           aarch64 なら64ビット
  getconf LONG_BIT   64

パッケージを展開し、SGM1.DAT、SONG.DAT、FPLAY.COM をプログラムと
同じフォルダに置き（ファイル名は大文字まで同じに）、そのフォルダで：

  chmod +x rudebreaker
  ./rudebreaker

パッケージには libSDL2-2.0.so.0 が同梱されているので、ほかに
インストールするものはありません。

デスクトップ環境：現在の Raspberry Pi OS のデスクトップは Wayland で
動いており、ゲームも標準で Wayland を使います。ウィンドウが開かない、
または表示がおかしい場合は X11 を指定してください：

  SDL_VIDEODRIVER=x11 ./rudebreaker

Raspberry Pi OS Lite（デスクトップなし）：SSHではなく、本体の
テキストコンソールから次のように起動します：

  SDL_VIDEODRIVER=kmsdrm SDL_AUDIODRIVER=alsa ./rudebreaker

ユーザーが video と input グループに入っている必要があります
（標準のユーザーは入っています）。入っていない場合は：

  sudo usermod -aG video,input $USER

を実行し、ログアウトしてから再ログインしてください。

動作の目安：Pi 4 または Pi 5 を推奨します。Pi 3 ではフルスクリーン
ではなく小さめのウィンドウで遊び、ほかのプログラムは閉じてください。

「cannot execute binary file: Exec format error」と表示された場合は、
32ビット版OSか、合わないパッケージを使っています。対応するのは
64ビット版 Raspberry Pi OS のみで、32ビット版の配布は終了しました。


3. 操作方法
-----------

キーボード（初期設定）：

  移動              方向キー、W A S D、テンキーの 8 4 6 2
  ショット / 決定   Z、スペース、テンキーの 0
  モード            X、N、M、Enter、テンキーのEnter
                    （サイドのオプションを攻撃型と防御型で切り替え）
  スペシャル        左右のShift
  スピード          C、左右のCtrl（下記参照）
  ポーズ / 戻る     Esc
  終了              F10
  フルスクリーン    F11（いつでも切り替え可能。FULLSCREEN
                    オプションと同じく保存されます）
  タイミング表示    F8（フレーム進行の情報を表示、7章）

ゲームパッド：

  一般的なPC用ゲームパッド（XInput・DirectInput）は自動で認識されます。
  ゲーム中に抜き差ししても構いません。

  移動              左スティックまたは十字キー
  ショット / 決定   下ボタン（XboxパッドのA）
  モード            右ボタン（B）
  スペシャル        左ボタン（X）
  スピード          上ボタン（Y）。標準配置でないパッドでは
                    ボタン4（4番目のボタン）。
  ポーズ            Start
  終了              Back / Select

SPEEDボタン：押すたびにプレイ中の自機の速度が、上がって下がってを
繰り返す順で切り替わります：

  LOW  ->  MID  ->  MAX  ->  MID  ->  LOW  ->  MID  ...

  LOW  低速
  MID  標準（初期設定）
  MAX  高速

上部のバーに現在の速度が SPD LOW、SPD MID、SPD MAX と表示されます。

各ゲームは MID で始まります。ボタンでの変更はそのゲームが終わるまで
有効です。各速度の実際の速さは GAMEPLAY の SHIP SPEED で決まります。

ポーズ：Escまたはパッドの START ボタンでのポーズはプレイ中のみです。
START は自動検出されます。SDLが認識するパッド（Xbox、PlayStation、
Switch など）では START/OPTIONS/+ ボタン、単純なジョイスティックでは
ボタン8か10、またはプレイ中に最初に押した10番より上のボタンです。
ポーズ中は RESUME と MAIN MENU のメニューが出ます。RESUME（または
Esc/START/B）でゲームに戻ります。MAIN MENU はゲームを終えてタイトル（コンパイルのロゴから）に
戻ります。タイトル、デモ、メニューではポーズしません。メニューではEsc（キーボード）または
Bボタン（パッド）で1ページ戻ります。
ポーズメニューは止まったゲーム画面の上に重ねて表示され、COLOR FILTER
とCRT効果はそのまま有効です。ポーズメニューはパッドでも操作できます：十字キーかスティックで移動、Aで決定、BかSTARTで再開。

ウィンドウの大きさは変更できます。画面はオリジナルの640x400の比率を
保ちます。


4. タイトル画面とCONFIGメニュー
-------------------------------

ロゴ、タイトル、ランキング表示、オープニングはオリジナルの画面です。
その前に無音のカードが流れます：粒子が飛んできてルードブレイカーの
ロゴになり、少し止まったあと、「30TH ANNIVERSARY EDITION」（白文字で
ロゴの幅いっぱいに広がり、着地すると一度やわらかく光ります）と
クレジットの行が下からせり上がります。全体で約2.5秒後にカードが
フェードアウトし、オリジナルのコンパイルのロゴと音楽が始まります。
どのキーやパッドのボタンでもカードを飛ばして、すぐにコンパイルの
ロゴへ進めます。SIDE PANELSがONのときは、ゲーム画面上部のスコア行を
左右に数ピクセル内側へ寄せ、パネルの枠で切れないようにしています。
タイトル画面には、ロゴの下中央に白い「30TH ANNIVERSARY EDITION」
（5秒ごとに文字のまわりがやわらかく光ります。左サイドパネルのロゴの
下でも同じ光が出ます）、10秒ごとに黄色と緑の間でなめらかに色が
変わるPUSH TRIGGER、そして (c) COMPILE 1996 と (c) SHMUPSBR 2026 の
クレジットが表示されます。
タイトルでショットを押すとゲーム開始、タイトルメニューからCONFIGを
開けます。
タイトルメニューの RETURN はゲームの最初（コンパイルのロゴ、デモ、
タイトル。オリジナルどおり）に戻り、EXIT はゲームを終了します。
メニューの行はタイトル画像の大きな (c) COMPILE 1996 の行に重なり
ますが、これはオリジナルどおりの配置です。

アトラクトモード（GAMEPLAY > ATTRACT MODE、初期設定 ON）：キーボードや
パッドに触れずにいると、オリジナルのループ（コンパイルのロゴ、イントロ
の飛行、タイトル、ランキング）が1回流れ、ランキングが終わるとすぐに
1ステージ分の30秒のデモが始まります（音楽なし、効果音のみ）。
ゲーセン風に画面中央で INSERT COIN が点滅しますが、ただのお遊びで
コインは不要です。そのあとまたループ、次のステージ
と続き、ステージ1から5まで順に回ります。どのキーやボタンでもデモは
終わり、タイトルの流れに戻ります。デモでは何も保存されません（ハイ
スコア、ランキング、設定とも）。デモの自機の動きは実際のプレイヤー
の軌跡に基づく、このポート独自の入力記録で、ゲームのデータではあり
ません。

2つのランキングは別物です。アトラクトモードのランキングはオリジナルの
ループの一部で、数秒間ひとりでに表示されて次へ進みます（キーは不要、
どのキーでもループを抜けます）。CONFIG の RANKING は同じ表を好きな
だけ眺めるためのもので、キーを押すと閉じます。

CONFIGには GAMEPLAY、GRAPHICS、SOUND、ALTERNATE VERSIONS、CONTROLS、RANKING、PASSWORD、
ORIGINAL PRESET、RESTORE DEFAULTS、BACK のページがあります。rudebreaker.cfg の設定名は以前と同じなので、
以前の版の設定もそのまま読み込めます。

GAMEPLAY

  項目の順番：DIFFICULTY、RANK、SUICIDE BULLETS、SHIP SELECT、DEFAULT
  SPEED、TRAINING、LOOP、ATTRACT MODE、I-FRAMES、BACK。

  DIFFICULTY       VERY EASY、EASY、NORMAL、HARD、VERY HARD。オリジナル
                   そのままの難易度です。NORMALがオリジナルの初期設定。
                   RBRANK.DATに保存されます。

  RANK             ADVANCED（初期設定）、CLASSIC、OFF。ADVANCED：パワー
                   、アイテム、勲章にも反応する隠しランクで、撃ち返し弾
                   とスコアボーナスが加わります（6章 RANK MODE ADVANCED
                   ）。CLASSIC：プレイ内容によって敵弾が速くも遅くもな
                   ります（6章）。OFF：弾速はオリジナルどおり固定。
                   ADVANCED が初期設定になるのは新しい rudebreaker.cfg
                   だけで、既存の設定はそのまま残ります。

  SUICIDE BULLETS  ON：敵が破壊されたときに撃ち返し弾を出します
                   （オリジナルのオプションと同じ）。OFF：出しません。
                   （pr9zgより前の版では表示が逆でした。保存された
                   設定は変わらないので、ゲーム内容は同じで、表示だけ
                   正しくなりました。）

  SHIP SELECT      オリジナルの同名オプション。武器の扱いを決めます：
                   ON：最初に「PLEASE SELECT YOUR OPTION」画面で武器を
                   1つ（VULCAN、LASER、MISSILE）選びます。以後の武器
                   カプセルはすべてその武器になり、ゲーム中ずっと
                   その武器のままです。
                   OFF（初期設定）：選択はありません。カプセルはV・L・M
                   の3種類が出て、別の文字のカプセルを取るとプレイ中に
                   武器が変わります。

  SHIP SPEED       STANDARD または AGGRESSIVE（初期設定）。STANDARD：
                   オリジナルと同じ LOW / MID / MAX の速さ。AGGRESSIVE：
                   LOW は15%遅く、MID は同じ、MAX は15%速くなります。
                   各ゲームは MID で始まり、ゲーム中の速度ボタンで
                   LOW / MID / MAX を切り替えます。デモは常に
                   オリジナルの動き。rudebreaker.cfg に ship_speed
                   として保存されます。

  TRAINING         ON：練習モード（5章）。OFF：通常のゲーム。

  LOOP             ON（初期設定）または OFF。OFF：オリジナルどおり、ステージ5の後に
                   エンディングで終わります。ON：ステージ5をクリアすると
                   2周目としてステージ1から再開し、その後も3周目と続き
                   ます。スコア、残機、武器はそのまま引き継がれます。
                   周回ごとに難しくなります（6章を参照）。
                   rudebreaker.cfg に保存されます。

  ATTRACT MODE     ON（初期設定）または OFF。ON：ランキング画面の後に
                   30秒のデモ（音楽なし、効果音のみ）、その後コンパイル
                   のロゴに戻ります。OFF：デモなし。
                   rudebreaker.cfg に保存されます。

  I-FRAMES         CLASSIC（初期設定）または NEW。CLASSIC：被弾後や
                   パワーアップ後の自機の無敵はオリジナルどおりの見た目
                   （赤い輪郭）。NEW：さらに赤い光が自機の表面を中心から
                   外へ波のように走り、スプライトの端で止まります。
                   オプションも合体している間は同じように光ります。
                   オリジナルの演出の赤を使い、脈打ち、残り時間が減る
                   につれて細くなるので、無敵が切れそうなのが分かります。
                   このポートが画面の上にドットそのまま（なめらかに
                   しない）で描き、カラーフィルターや CRT の設定もかかり
                   ます。変わるのは見た目だけで、無敵時間は同じです。
                   rudebreaker.cfg に保存されます（iframes=classic / new）。

  BACK

GRAPHICS

  項目の順番：FULLSCREEN、SCALING、ASPECT、ORIENTATION、SIDE PANELS、
  PALETTE、BULLET COLOR、HITBOX、6つのCRT効果、FRAME
  PACING、BACK。

  FULLSCREEN       OFF（初期設定）または ON。ゲームの縦横比を保った
                   まま画面全体に表示し（横長の画面では SIDE PANELS
                   が左右を埋めます）、マウスポインタを隠します。
                   F11 でいつでも切り替えられます。
                   rudebreaker.cfg に保存されます。

  SCALING          画面やウィンドウへの拡大方法。AUTO（初期設定）：
                   INTEGER が画面の高さの80%以上を使えるときは
                   INTEGER、そうでなければ SHARP。720p と 1080p では
                   SHARP、1440p・4K・800x480 では INTEGER になります。
                   INTEGER：ゲームの1ラインを同じ整数倍の画面ラインで
                   表示します（周囲は黒枠）。ASPECT 8:5 ではすべて同じ
                   大きさの正方形ドット、ASPECT 4:3 では高さが整数倍
                   （2倍 = 800ライン、3倍 = 1200）で、幅は4:3になるよう
                   合わせます。SHARP：縦横比を保って画面いっぱいに、
                   ぼかさずに表示します（一部のドットが1画素大きく
                   なります）。SMOOTH：同様に画面いっぱいに、なめらかな
                   （バイリニア）フィルタで表示します。ウィンドウが
                   INTEGER には小さすぎるときは SHARP と同じになります。
                   SIDE PANELS 表示中は16:9の画面（パネル込み）が全体を
                   使い、INTEGER（または AUTO が INTEGER を選んだとき）
                   はその中のゲーム画面をライン数の整数倍で描き、周りを
                   黒にして中央に置きます。rudebreaker.cfg に保存されます。

  ASPECT           画面全体の縦横比です。
                   4:3（初期設定）：640x400の画面をPC-98のモニターと
                   同じ形で表示します。1ドットは横より1.2倍縦長（5:6）
                   で、アートが本来見られるはずの形です。1080p では
                   SHARP で1440x1080になります。8:5：640x400の画面を
                   そのまま（16:10、正方形ドット）表示します。
                   オリジナルより少し平たく見えます。8:5 では自機の縦の
                   移動を1.2倍にして、画面を横切る時間を4:3と同じに
                   します（デモはオリジナルのまま）。SIDE PANELS の
                   ゲーム画面も同じ設定に従います（8:5 では上下に黒帯）。
                   rudebreaker.cfg に保存されます。

  ORIENTATION      0（初期設定）、90、180、270。画面全体（ゲーム、タイ
                   トル、メニュー）を時計回りにその角度だけ回します。モ
                   ニターを縦置きや逆さまに設置した場合に使います。モニ
                   ターから自動判定はせず、自分で選びます。0と180は通常
                   の横長レイアウト。90と270は縦画面（TATE）レイアウト
                   ：上にタイトル画面の枠つきロゴ、その下に SCORE、
                   LOADOUT、NO DEATH と SPEED。中央にゲーム画面を横幅い
                   っぱいに表示し、下に RANK、HIT RATIO / HIT COUNT、
                   LEVEL / TIME、EXTENDS / I-FRAMES、MEDALS と INPUT を
                   並べます。90ではモニターの右端が上、270では左端が上
                   になるように置きます。FULLSCREEN ON がおすすめです。
                   SCALING と ASPECT は通常どおり効きます。
                   rudebreaker.cfg に orientation として保存されます。

  SIDE PANELS      ON（初期設定）/ OFF。ON：16:9のウィンドウか全画面では、
                   ゲーム画面を中央に置き、左右に情報パネルを表示します：
                   ランクのグラフ、装備、残機、無敵時間、速度、スコア、
                   撃墜率、勲章、レベル、時間、NO DEATH、入力を表示する
                   アーケードスティック。ロゴと横のアートは、お手持ちの
                   データのタイトル画面から取り出しています。
                   OFF、または4:3 / 16:10のウィンドウ：従来の見た目。
                   LOADOUT（装備）は2つのレベルを、1レベル1ブロックで
                   表示します（レベル1も含み、最初のブロックが埋まります）。
                   SHOTはメインショット：4段階なので4ブロック。レベル2、
                   3、4（MAX）はパワーアップアイテム2個、10個、18個で
                   上がり、ブロックはアイテム1個ごとに埋まっていきます。
                   ミスすると1段階下がります。V / M / L のサブウェポンは
                   それぞれ3段階で3ブロック。持っている武器と同じ
                   カプセルを取ると1段階上がり、MAXではカプセルが1000点に
                   なります。別の色のカプセルは、レベルを保ったまま武器を
                   変えます。サブウェポンを持っているときに被弾すると、
                   残機の代わりにサブウェポンを失います。そのときは
                   NO SUB と空のカプセル枠が表示されます。EXTENDS は自機と
                   残機の数を表示します。
                   I-FRAMES は無敵時間を円グラフで表示します：付与された
                   ときは塗りつぶした円、減るにつれて12時の位置から時計回りに
                   扇形が開き、なくなると薄い円の輪郭だけになります。
                   黄色：パワーアップアイテムまたはカプセル。紫：被弾後
                   または復活後。
                   ランクのグラフでは、ミスするたびにドクロが付きます。
                   グラフは直近60秒を表示してスクロールし、古いデータが
                   左へ消えていきます。各ステージの開始時にグラフは
                   消去されます（ランク自体は消えません）。
                   RANK OFF（またはトレーニング中）は、グラフ枠に
                   緑色で RANK SYSTEM / OFFLINE と表示され、15秒ごとに
                   CRT風の走査線がゆっくり上っていきます。ランクの
                   数値は表示されず、ランクはゲームに一切影響しません。
                   ランクはステージをまたいで引き継がれ、新しいゲームで
                   だけリセットされます。横の小さな「x1.05」は現在の
                   ランク上昇倍率です。
                   ゲーム画面は ASPECT に従います。4:3（初期設定）は
                   PC-98のモニターと同じ形（ピクセルが横より1.2倍縦長）、
                   8:5 は正方形ピクセルです。
                   HIT COUNT は、そのステージで倒した敵の数 / ステージの
                   固定の敵数を表示します（ステージ1～5で369、315、128、
                   205、46：各ステージ自体が配置する敵。無限に湧く敵、
                   弾を出す発生源、ランクやタイミングで増える敵は数えず、
                   弾、アイテム、隠しポイントも含みません）。HIT RATIO は
                   同じ値を百分率とバーで表示します。ミスするとステージの
                   一部をやり直しますが、数は合計を超えません。
                   MEDALS は、各ステージ（1～5）に10個ずつ隠された勲章の
                   うち、そのステージで取った数を表示します。ゲーム自身の
                   勲章カウンターをそのまま使っており、出現した勲章を
                   取ったときだけ増え、ステージごとに0に戻ります。
                   NO DEATH は、ミスするまでは YES、ミスすると NO を
                   表示します（回数は表示しません）。全5ステージと
                   コンティニューを通して NO のままで、新しいゲームを
                   始めたときだけ YES に戻ります。トレーニング中は枠の
                   見出しに TRAINING も表示されます。
                   LOOP ON で2周目以降は、RANK 枠の見出しに周回数も
                   表示されます：LOOP 2、LOOP 3 …。1周目と LOOP OFF
                   では表示されません。
                   縦画面レイアウトは SIDE PANELS の選択肢ではなくなり
                   、ORIENTATION の 90 か 270 で使います。以前の版で
                   SIDE PANELS を TATE にした設定は、ON と ORIENTATION
                   90 として読み込まれます。

  PALETTE          MODERN（初期設定）：Filipeによるゲームの色の
                   再調整。ORIGINAL：PC-98の色。

  BULLET COLOR     PINK（初期設定）、LILAC、BLUE、GREEN、ORIGINAL。
                   破壊できない敵弾を、元の色（赤・オレンジ・金）に
                   関係なくすべて塗り替えます。ボスのレーザーも
                   ケイブ風に全長を塗り替えます。暗い縁、本体、明るい
                   芯の陰影はそのままです。ゲームはこれらの弾を色では
                   なくオブジェクトの種類で区別しています：敵弾には
                   弾のビットがあり、「撃ち落とせる」ビットがありません。
                   撃ち落とせる弾、敵、アイテム、自機のショットは元の色の
                   まま。弾を撃ち落としたあとに残る無害な火の玉も同じです。
                   ORIGINALはすべての弾をゲームのままにします。

  HITBOX           OFF（初期設定）、PINK、LILAC、BLUE、GREEN、RED
                   （以前の WHITE は PINK になります）。自機の上に、実際の当たり判定（12×18ピクセル）
                   を閉じた細い枠と40％の半透明の塗りで表示します
                   （機体は見えたままです）。枠の色は敵弾の色と
                   同じにはなりません：その色は飛ばされ、BULLET COLOR
                   を当たり判定の色に変えると、当たり判定は次の色に
                   進みます。BULLET COLOR が ORIGINAL のとき RED は
                   飛ばされます（オリジナルの弾は赤のため）。
                   rudebreaker.cfg に保存されます。

  COLOR FILTER     ORIGINAL（初期設定）、GAME BOY、VIRTUAL BOY、
                   COMMODORE 64、GAME GEAR、PC ENGINE、ZX SPECTRUM、MSX2、MEGA DRIVE（ALTERNATE VERSIONS > CUSTOM で設定）。
                   ゲーム画面の色だ
                   けを、プレイ中（デモを含む）だけ変えます。タイトル、
                   メニュー、ランキング、名前入力、サイドパネルは常に本
                   来の色のままです。ゲームの絵やパレットは変わらず、
                   PALETTE もそのまま効きます。フィルターはお遊びで、そ
                   れぞれ実機の特徴を誇張しています。GAME BOY：明るさで
                   初代ゲームボーイの緑に。反応の遅い液晶（動くものに残
                   像）とドットの格子が見えます。VIRTUAL BOY：黒地に赤
                   の濃淡。LEDの短い残光とLED列のすき間。COMMODORE 64：
                   C64の16色（Pepto）、2:1の横長ドットのマルチカラーモード（160x200）、背景は4x8セルごとに共通の黒と3色、スプライト・弾・アイテムはVIC-IIのスプライト規則（全スプライト共通の2色＋各自の1色）、PALの色混ざり
                   （各ラインが上のラインと混ざります）。GAME GEAR：
                   GAME BOY風の見た目のカラー版。4096色（各4ビット）か
                   ら毎フレーム選んだ最大31色（背景16＋スプライト15、スプライトの0番は透明）、
                   大きくくっきりしたドット（約240x200相当）、液晶の残像なし、くっきりした輪郭、はっきり見える液晶のドット格子、スプライトや弾が背景から浮き出るよう強めたコントラストと彩度。PC ENGINE：強く鮮やかで明るい色（HuC6260 VCE：各3ビット、512色、レベルは v×255/7）、背景は8x8タイルごとに16色、スプライトは16x16ごとに15色＋透明、ディザなし、コンポジ
                   ットのにじみはわずか。解像度は実機の256x224。実機と同じく背景のドットはスクロールする背景に、スプライトとスコア行のドットは画面に固定されるので、スクロール中も形が変わりません。ZX SPECTRUM：カラークラッシュも含めた実機の制約。スペクトラムの192ライン相当の大きな正方形ドットで、8x8セルごとに使える色は基本8色からINKとPAPERの2色だけ、BRIGHTビットは2色で共通です。各ドットはそのどちらかになります。多くのスペクトラムのゲームと同じく黒いPAPERを優先し、輪郭や細部は残します。背景のセルは背景そのものに固定されて一緒にスクロールするため、色がずれたりちらついたりしません。スプライトは種類ごとに変わらない専用のINK色を持ち、その色と黒で描かれます。パワーアップのカプセルは武器の色になります（VULCAN は赤、LASER は青、MISSILE は白）。画面上の文字（上部のスコア行、ステージ間の表示）はセルの制約を無視し、低解像度・単色・不透明で背景の上に描くので消えません。MSX2：SCREEN 5風、256x212（背景のドットは背景に、スプライトとスコア行のドットは画面に固定されるので揺らぎません）、MSX2の512色（赤・緑・青各3ビット）からシーンに合わせて選んだ16色。色の組はちらつかないようにゆっくり変わり、各ドットは16色のうち最も近い色になります。カラークラッシュはありません。MEGA DRIVE：インターレースモード、ゲーム画面の横240ドット・ゲーム本来のライン数（320x224の格子ではスクロール中にスプライトも含めて全体が揺れて見えました）、メガドライブの512色（各3ビット、実機のDACレベル）を15色×4ライン＋黒の背景色で。2ラインは背景、2ラインはスプライト用で、8x16タイルごとに1ラインを使い、ちらつかないようラインはゆっくり変わります。保存されません。起動するたび、またゲームが終わるたびに ORIGINAL に戻ります（rudebreaker.cfg の古い color_filter は無視され、削除されます）。

  CUSTOM EQ、SOUND TEST、BACK。

  SOUND CHANNELS   EXTRA（初期設定）：効果音を2つ目のエミュレート音源で
                   鳴らし、音楽は途切れません。ORIGINAL：PC-98と同じく
                   効果音が音楽とFM音源を共有するため、効果音で音楽の
                   パートが一瞬途切れることがあります。
                   rudebreaker.cfg に保存されます。

  MUSIC CHIP       ORIGINAL（初期設定）、SID、GAME BOY、PSG、PC ENGINE、
                   VIRTUAL BOY、ZX SPECTRUM、MSX2、MEGA DRIVE（ALTERNATE VERSIONS > CUSTOM で設定）。
                   お遊び機能で、BGMをPC-98のFM音源の代わりに、ほかの機
                   種の音源を簡単にまねたものから鳴らします。ゲームがFM
                   音源に送る音（音程、キーオン／オフ、音量）を読み取り、
                   重要なものからその音源の持つチャンネルに割り当てるの
                   で、パートが欠けたり、わざと粗い音になったりします。
                   正確な移植ではありません。SID（コモドール64）：のこ
                   ぎり波、パルス波（幅が揺れます）、三角波、ノイズの3
                   音とレゾナンス付きフィルター。GAME BOY：パルス2ch、
                   ベース用の4ビット波形メモリ1ch、ノイズ1ch、4ビット
                   DAC。PSG（ゲームギアのSN76489）：矩形波3chとノイズ、
                   音量は2dB刻み、約110Hzより低い音は出ません。PC
                   ENGINE：32ステップ5ビットの波形メモリ6ch。VIRTUAL
                   BOY（VSU）：32ステップ6ビットの波形メモリ5ch（5ch目は
                   スイープとモジュレーション付き）とノイズ1ch、約76Hz
                   より低い音は出ません。ZX SPECTRUM（128KのAY-3-8912、1.7734MHz、モノラル）：矩形波3chと共有ノイズ1つ、ハードウェアエンベロープ、16段階の対数音量。MSX2（PSGとコナミのSCCカートリッジ、FMなし）：PSGの矩形波3chとノイズ、SCCの32ステップ波形メモリ5ch（最後の2chは波形を共有）。ギターは根音と5度のSCCのこぎり波2つに1オクターブ下のPSG矩形波を重ね、ベースなどはSCC、ドラムはPSGの矩形波とノイズです。MEGA DRIVE（メガドライブ1：YM2612のFM 4オペレーター6chとSN76489 PSG）：ブラス、ベース、ギターのFM音色（ギターはエミュレートしたYM2612コアで鳴らすメタル系のFMギター。高いフィードバックでチップ自体で歪ませ、約11セント低い1オクターブ下と2オクターブ下を重ね、短いピッキングの音は音程へ滑り込み、離すと下がる。ビブラートなし、アンプ／キャビネットなし）、YM2612の粗い音量段階と9ビットDACの音。ドラムはPSGの矩形波とノイズで、サンプルは使いません。SOUND TEST
                   も選んだ MUSIC CHIP で鳴ります。COLOR FILTER とは独
                   立しています。保存されません（起動するたび、ゲームが終わるたびに ORIGINAL に戻ります）。
                   歪んだギターにチップを1つまるごと使い（VIRTUAL BOY と SID はギターのパートごとに1つ）、
                   全ボイスで1本のギターを鳴らします（SID：シンク／リ
                   ングとフィルター、GAME BOY：パルス2つと歪んだ波形と
                   ノイズのピッキング、PSG：矩形波3つとノイズのピッキン
                   グ、PC ENGINE と VIRTUAL BOY：波形メモリとノイズのピッ
                   キング、ZX SPECTRUM：エンベロープによるうなるのこぎり波、パワーコードの5度とオクターブ、ノイズのピッキング。MSX2：根音と5度のSCCのこぎり波2つ、1オクターブ下のPSG矩形波、PSGノイズのピッキング。MEGA DRIVE：根音と5度の歪ませたFMとノイズのピッキング）。そ

CONTROLS

  JOYSTICK         ON または OFF：ゲームパッドを読むかどうか。パッドを
                   つなぐと自動で ON になりますが、ここで OFF にすると、
                   再起動後もパッドをつなぎ直しても、ON に戻すまで OFF
                   のままです（joystick=off として保存。初期設定は auto）。
                   下の DEVICE には使用中のコントローラー1台の名前、
                   または NONE が出ます。2台つないでいるとき、もう1台を
                   抜き差ししても使用中のものはそのままです。
  DEFINE KEYS      UP、DOWN、LEFT、RIGHT、FIRE、MODE、SHIFT、PAUSE、
                   SPEED を割り当て直します。動作を選んで、新しいキーか
                   パッドのボタンを押してください。RESTORE DEFAULTS で
                   3章のキーに戻ります。
                   パッドのボタンは読みやすい名前で表示されます。種類が
                   分かれば Xbox 系は A / B / X / Y、LB / RB、VIEW / BACK、
                   MENU / START、PlayStation 系は CROSS、CIRCLE、SQUARE、
                   TRIANGLE、L1 / R1、Nintendo 系は位置つきの文字です。
                   トリガー、スティック、D-PAD、BACK PADDLE 1-4、
                   TOUCHPAD CLICK、シェア／キャプチャボタンにも名前が
                   あります。
  BACK

SOUND TEST（SOUND から開きます）

  SOUND            音楽と効果音の ON / OFF。
  BGM              左右で曲（0～47）を選び、ショットで再生。
  SE               左右で効果音（0～47）を選び、ショットで再生。
  PLAY / PAUSE / STOP   プレイヤーの操作。
  MUSIC CHIP / SFX CHIP   ALTERNATE VERSIONS の音源チップを、ここで
                   左右で切り替えられます。再生中の曲もすぐ切り替わり
                   ます。あちらと同じく保存されず、次の起動時とゲーム
                   終了後に ORIGINAL に戻ります。
  一番上の行に曲と状態が出ます。下のメーターは再生中の音の VU で、
  緑から赤への LED セグメントとピークホールド付きです。
  （一部の番号は無音です。オリジナルのデータで空になっています。）

PASSWORD           オリジナルのパスワード画面を開きます。

                   （比較などに）。Fire を1回押すと PRESS AGAIN と出るの
                   で、もう1回 Fire で確定します。LOOP OFF、RANK OFF、
                   SHIP SELECT ON（ディスクどおりの武器選択）、SOUND
                   CHANNELS ORIGINAL、オリジナルのパレット、COLOR FILTER
                   なし、CRT なし、サイドパネルなし、オリジナルの弾の色、

                   I-FRAMES CLASSIC、オリジナルの音源チップ、OUTPUT PROFILE

                   ウィンドウ、スケーリング、アスペクト、画面の向き、

                   ハイスコア、ランキング（RBRANK.DAT）、パスワードは
                   そのままで、何も削除しません。あとからどの設定も
                   変えられます。rudebreaker.cfg に preset=original と
                   書くと、次の起動時に1回同じことをします。

コントローラーの設定例（Steam Deck ほか）

  SDL が知っているパッドなら設定なしで動きます：スティックか D-PAD で
  移動、下のボタンでショット、右のボタンで MODE、START でポーズ。ほかは
  DEFINE KEYS で設定してください。
  Steam Deck（デスクトップでもゲームモードでも、Steam Input の
  「ゲームパッド」レイアウト）：左スティックか D-PAD で移動、A で FIRE、
  B で MODE、X で SHIFT、MENU（画面右のボタン）で PAUSE。背面ボタン
  （L4、L5、R4、R5）は BACK PADDLE 1-4 として届くので、DEFINE KEYS で
  SPEED や SHIFT を割り当てられます。Steam がほかのボタンに割り当てて
  いる場合は Steam Input 側で設定してください。実機の Deck ではまだ
  試していません。

LINUX：WAYLAND と X11

  Linux ではまず X11 で開きます（Wayland のデスクトップでは XWayland
  経由）。どこでも動く方法です。Wayland で直接動かすには
  SDL_VIDEODRIVER=wayland ./rudebreaker で起動し、戻すには変数を外すか
  SDL_VIDEODRIVER=x11 にします。

5. トレーニングモード
---------------------

TRAINING は練習用です：

  - 自機は被弾しません。武器も残機も失いません。
  - 隠し勲章のポイントが、その場でずっと赤く点滅します。普段は撃って
    いるときにだけ見える赤い点滅と同じもので、場所を覚えられます。
    勲章を出すには通常どおりポイントを撃ち続ける必要があり、スコアも
    変わりません。
  - RANKは使われず、難易度はDIFFICULTYの設定のままです。
  - トレーニングでのスコアはハイスコア表に載らず、そのプレイの内容は
    RBRANK.DATに保存されません。

通常どおり遊ぶときは TRAINING をOFFにしてください。


6. スコア・セーブ・オリジナルの隠し要素
---------------------------------------

ハイスコアと設定は、オリジナルの形式でRBRANK.DATに保存されます。
新しいスコアは名前を入力したときに保存されます。

難易度とゲームのルールはすべてオリジナルどおりです。

RANK（GAMEPLAYのオプション、新しい設定ファイルでの初期設定はADVANCED）は、ザナックのランク
システムを参考にしたこの移植版独自の要素です。内部のランク値は、
生き残っている間と得点したときに上がり、ミスするとリセットされます
（下記参照）。上昇の速さはこの移植版の以前のバージョンの3分の1で、
そこにゲームの進行とともに大きくなる倍率がかかります：メインショットの
レベルが1つ上がるごとに+1%、サブウェポンのレベルが1つ上がるごとに+5%
（1000点になるだけのカプセルや、色が変わるだけのカプセルは数えません）、
スコアエクステンドで残機が1つ増えるごとに+5%。倍率は新しいゲームの
たびにx1.00から始まり、ミス時のリセットやDIFFICULTYによる上限は
変わりません。
サブウェポンを失う（被弾してメインショットだけになる）と、現在の
ランクの3分の1が下がります。下がった分は記憶され、サブウェポンを
取り直すと戻ります（DIFFICULTYの上限は超えません）。新しいゲームで
消去されます。ランクが高いほど敵弾が速くなり、これはDIFFICULTYを
上げたときと同じ仕組みです。ほかは何も変わらず、ボーナスは選んだ
DIFFICULTYのままです。DIFFICULTYは開始点と下限を決めます：ランクに
よって、選んだ難易度より弾が遅くなることはありません。VERY EASYと
EASYではランクは半分までしか上がらず、HARDとVERY HARDでは半分から
始まります。ランクは新しいゲームのたびにリセットされます。

プレイ中の難易度でランクが最大になると、難易度が1段階上がり、ランクは
その難易度の開始点からやり直しになります。これは選んだDIFFICULTYの
上限まで続きます：

  VERY EASY  -> NORMALまで（EASYを経由）
  EASY       -> HARDまで（NORMALを経由）
  NORMAL     -> HARDまで
  HARD       -> VERY HARDまで
  VERY HARD  -> VERY HARDのまま

上限ではランクは最大のままです。難易度が上がるたびに、サイドパネルの
LEVEL枠が2秒間点滅し、RANKのグラフのその時点に上向き矢印付きの緑の
線が入ります（ミスはドクロ）。また、ゲーム本来の1000点ボーナスが入り、
自機の上に 1,000 の表示が出ます。

NORMALまたはVERY HARDを選んだ場合、上限に達してランクが最大のときは、
プレイ20秒ごとに敵弾が1%ずつ速くなり、最大+25%になります。LEVEL枠に
表示されます（例：V.HARD +3%、HARD +3%）。被弾（サブウェポンを失う）
またはミスで+0%に戻ります。

ミスすると、選んだDIFFICULTYとその開始ランクに戻ります。難易度の
上昇で変わるのはランクが変えるもの（敵弾の速さとランクの範囲）だけ
で、スコア、ボーナスなどはすべて選んだDIFFICULTYのままで、保存された
設定も変わりません。トレーニング中は無効です。RANK OFFではオリジナルと
まったく同じで、難易度の上昇も弾の加速も+1000ボーナスもなく、
サイドパネルのランクのグラフには RANK SYSTEM / OFFLINE と表示されます。

RANK MODE ADVANCED（RANKをADVANCEDに。rank_mode=advancedとして保存）
では、上のルールの代わりに0〜1000の隠しランクを使います。数値は表示
されません。ランクのグラフに目盛りはなく、その下の細いバーは次のLEVEL帯までの進み具合です。帯の始めで空、次の帯で満タンになり、LEVEL欄が光り、ランクのグラフに上向きの矢印が付き（CLASSICと同じ）、バーは新しい帯で最初から始まります。上限ではバーは満タンのまま、明るく枠付きで表示されます。開始値と上限はDIFFICULTYで決まります：

  VERY EASY  開始 0、  上限 400
  EASY       開始 80、 上限 550
  NORMAL     開始 150、上限 800
  HARD       開始 280、上限 900
  VERY HARD  開始 400、上限 1000

開始値より下がることはありません。上がる条件：
  - 生きている間、毎秒。最後のミスからの時間が長いほど速く上がります
    （3分後に最大3倍）。
  - メインショットのレベルが上がったとき。レベル3・4の間は毎秒少し。
  - サブウェポンを取ったとき、またはレベルが上がったとき（強いほど多い）。
  - 勲章を取ったとき（ステージ内で取るたびに価値が上がります）。
  - 残機1機につき毎秒少し（5機まで）。
  - ショットボタンを押している間、毎秒少し。
NO DEATHがYESの間は、上昇がすべて10%増えます。
ミスすると15〜25%下がり（高いほど多く）、生存ボーナスはリセット。
サブウェポンを失うと少し（4%）下がります。

変化するもの：
  - 敵弾の速さがランクに合わせてなめらかに変わります。選んだ
    DIFFICULTYの速さ（これより遅くはなりません）から、最上部で
    VERY HARDの速さまで。850を超えるとさらに最大15%速くなります。
  - 700以上では、オプションがOFFでも、倒した敵が撃ち返し弾
    （SUICIDE BULLETSと同じ）を出します。700未満では選んだ設定に
    戻ります。
  - スコア：得点はランク1000で最大50%増えます（ランク/1000の半分）。
  - LEVEL欄はランクの帯（V.EASY〜V.HARD、DIFFICULTY未満にはならない）
    を表示し、帯が上がると光ります。
敵の弾の発射間隔や弾数は変わりません。ゲームデータでは発射の
タイミングが各敵のスクリプト内の独自カウンタなので、パターンを
変えずに全敵へ適用できないためです。
LOOPでは、ループごとに開始値が100、上限が50上がり（最大1000）、
ランクの上がる速さは周回数倍になります（下のLOOPを参照）。
トレーニング中は無効です。RANK OFFですべて無効になります。

LOOP（GAMEPLAYの項目、初期設定はON）はこの移植版で追加された機能
です。LOOP ON では、ステージ5をクリアしてもエンディングにならず、
2周目としてステージ1から再開し、その後も3周目と続きます。スコア、
残機、武器は引き継がれます。新しい周回ごとに：

  - 基本難易度が前の周より1段階上がります。出発点は選んだ
    DIFFICULTY です（VERY EASY → EASY → NORMAL → HARD → VERY
    HARD）。VERY HARD に達するとそのままで、下の周回倍率だけが
    上がり続けます。新しい難易度（ゲーム自身のその難易度の敵弾と
    敵の耐久力の設定）は、その周のステージ1の開始時から有効です。
  - ランクは新しい基本難易度の開始値からやり直しです。難易度上昇の
    上限、ランクの範囲、上限での弾の加速は、1周目で選んだ
    DIFFICULTY に従うのと同じように基本難易度に従います（例：
    NORMAL のゲームは2周目で HARD になり、そこから VERY HARD まで
    上がれます）。
  - ランクで決まる値はすべて周回数倍になります：1周目は×1、
    2周目は×2、3周目は×3…。対象はランクの上がる速さ、ランクが
    敵弾の速さに加える量、上限での加速の+1%の刻みです。上限：倍率は
    ×8で止まり（8周目以降）、敵弾の速さはゲーム自身の VERY HARD の
    値を超えず、上限での加速は+25%×倍率までですが+50%を超えません。
  - 2周目以降（トレーニング以外）は、どちらのランクモードでもランク
    の上昇量が周回数倍になります。さらに周内のランクで敵弾が速く
    なります：その周のランク範囲（開始値〜上限）を10段階に分け、
    1段階ごとに 5%×(周回数−1) 速くなります（2周目は1段階+5%、
    3周目は+10%…、最大+100%）。
  - 2周目以降は SUICIDE BULLETS が常に ON になります（メニューの
    設定は保持され、1周目や新しいゲームで再び有効になります）。
  - 2周目以降はボスのHPが増えます：各ステージのボスは周回が1つ
    増えるごとに+50%（2周目×1.5、3周目×2…）、最終ボス（ステー
    ジ5の要塞）は+100%（2周目×2、3周目×3…）。周回倍率は×8で
    止まり、HPには上限があるのであふれません。
  - ミスすると、その周の基本難易度とその開始ランクに戻ります。
  - 2周目からは、サイドパネルの RANK 枠の見出しに周回数を表示します
    （LOOP 2、LOOP 3 …）。1周目は表示されません。カウントは99で
    止まります。
  - ゲームオーバーで終了し、新しいゲームは選んだ DIFFICULTY で
    1周目から始まります。
  - トレーニング中も LOOP ON ならステージ5の後にステージ1から
    再開しますが、難易度と倍率は変わりません。

LOOP OFF では、オリジナルとまったく同じくステージ5の後に終わります。

オリジナルのデバッグ用隠しコマンドもコードに残っています。プレイ中に
Escでポーズし、N E K O C O と入力します。その後：

  2   無敵の切り替え
  3   デバッグ表示の切り替え
  1   押している間、フレーム待ちなしで動作（早送り）
  4   エンディングへ移動

オリジナルの隠し機能で、手を加えていません。


7. フレーム進行と垂直同期
-------------------------

オリジナルのゲームロジックは毎秒約30.67フレームで動きます。どのPCでも
この速度を保つので、オリジナルより速くなることはありません。

グラフィックドライバーが対応していれば、モニターの更新（垂直同期）に
合わせます：

  SMOOTH（初期設定）  60、120、240Hzのモニターでは、ゲームの1フレームを
                      ちょうど2、4、8回の更新で表示します。動きは完全に
                      均一です。このときゲームは毎秒30.00フレームとなり、
                      オリジナルより約2%遅くなりますが、気付かない程度です。

  EXACT               ゲームを正確に毎秒30.67フレームで動かし、更新の
                      たびに最新のフレームを表示します。60Hzの画面では
                      動きにわずかな周期的なムラが出ます。

ほかのリフレッシュレート（75、144、165Hzなど）では常にEXACTになります。
垂直同期が使えない場合は、タイマーで30.67に合わせます。

F8で、モード、測定したリフレッシュレート、タイミングの統計を小さく
重ねて表示します。同じ情報は、起動時と終了時にプログラムと同じ
フォルダの pace.txt に書き出されます。動きの滑らかさの問題を報告する
ときに役立ちます。


8. 意図的に外したオリジナルのオプション
---------------------------------------

オリジナルのオプションメニューにあった次の項目は、この移植版では
表示しません：

  AUTO SHOT、WAIT、PRIORITY、FRAME SKIP、SWAP KEYS

これらはPC-98のハードウェアの速度や制限を補うためのもの、またはPCの
操作設定で代わりになるものです。最近のPCなら処理落ちもコマ落ちもなく
フルスピードで動き、速度は移植版のフレーム進行（7章）で固定され、
キーの入れ替えはDEFINE KEYSで行えます。オリジナルの INVINCIBLE と
NAME ENTRY の項目は TRAINING に置き換えています。


9. 既知の制限
-------------

  - 垂直同期とSMOOTHのフレーム進行は、まだすべてのモニターと
    グラフィックカードで試してはいません。動きが滑らかでない場合は
    EXACTを試し、pace.txtを送ってください。
  - これはテスト版です。オリジナルと見た目や音が違うところがあれば
    お知らせください。


10. 不具合の報告
----------------

見た目、音、操作感がおかしいときは、次の情報を送ってください：

  1. 何が起きたか、本来どうなるはずだったか。
  2. 再現手順（ステージ、モード、メニュー、押したボタン）。毎回
     起きるか、ときどきかも。
  3. できればスクリーンショットか短い動画。
  4. WindowsまたはLinuxのバージョン、グラフィックカード、モニターの
     リフレッシュレート、使っているコントローラー（キーボードか、
     どのゲームパッドか）。
  5. PACINGの設定（SMOOTHかEXACT）と、ゲームフォルダの pace.txt
     （終了するたびに書き直されるので、問題が起きた直後にコピー
     してください）。
  6. ビルド名：Rude Breaker 30th AE pr9ze。
