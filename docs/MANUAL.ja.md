RUDE BREAKER 30th AE - PC版移植 - 取扱説明書
=============================================

ビルド pr9ze - 2026年10月31日

ほかの言語：英語（MANUAL.md / .txt）、ポルトガル語（MANUAL.pt-BR.md / .txt）。


1. 概要
-------

本作は、コンパイルがNEC PC-98向けに制作した縦スクロールシューティング
「ルードブレイカー（Rude Breaker）」（ディスクステーション、1996年）の
PC（Windows・Linux）移植版です。

Rude Breaker 30th AE（30th Anniversary Edition、30周年記念エディション）は、
1996年4月5日にディスクステーション Vol.10 で発表されてから30年を記念する
ものです。ゲーム本編はそのままに、次の要素を追加しています：

  - SPEEDボタン：プレイ中に自機の速度を切り替えます。上部のバーに
    SPD表示が出ます（3章）。
  - RANK：ザナック風のランクシステム。初期設定はON（4章・6章）。
  - MODERNパレットが初期設定になりました（ORIGINALも選べます）。
  - プレイ中の武器切り替え（SHIP SELECT OFF）が初期設定になりました
    （4章）。
  - Escでのポーズはプレイ中のみ。タイトルやメニューではポーズしません。
  - 最終ボスの誘導弾の軌跡スプライトが、オリジナルと同じく飛ぶ方向を
    向くようになりました。
  - 30th AEのマークとShmupsBR 2026のクレジットを入れた新しいタイトル
    画面。

この移植はリメイクではありません。オリジナルのデータファイルから、
オリジナルのゲームスクリプトとロジックをそのまま動かしています。敵の
攻撃パターン、スコア、ボスの耐久力、難易度はすべてオリジナルのコード
どおりです。音楽はオリジナルのFPLAYドライバーを、本作が想定していた
PC-98のFM音源チップYM2203のエミュレーション（ymfm）で鳴らしています。

PC側では、ウィンドウ、サウンド出力、キーボードとゲームパッド、
フレームの進行、CONFIGメニューの各種オプションを扱います。

重要：ゲームデータ（SGM1.DAT、SONG.DAT、FPLAY.COM）は著作物です。公開版の
移植には含まれておらず、再配布はできません。ご自身が正規に入手した
ゲームのものを使ってください（2章）。これらを含む非公開のテスト版は、
そのテスターだけのものです。共有しないでください。


2. インストール・起動・ゲームファイル
-------------------------------------

フォルダを好きな場所に展開してください。インストールは不要です。

  Windows：rudebreaker.exe を実行します。
  Linux：  そのフォルダでターミナルから chmod +x rudebreaker を実行し、
           続けて ./rudebreaker を実行します。

移植版のファイル：

  rudebreaker.exe       ゲーム本体（Windows）。
  SDL2.dll              ウィンドウ・サウンド・ゲームパッド用ライブラリ
                        （Windows）。
  rudebreaker           ゲーム本体（Linux x86_64）。
  libSDL2-2.0.so.0      同じライブラリ（Linux）。
  LICENSE-ymfm.txt      音源エミュレーターymfmのライセンス。
  LICENSE-SDL2.txt      SDL2ライブラリのライセンス。
  MANUAL.txt / .md      説明書。

ゲームファイル

移植版自体にはゲームデータが入っていません。お手持ちの
ルードブレイカー（ディスクステーション Vol.10、PC-98）から読み込みます：

  SGM1.DAT     必須   ステージ、スプライト、スクリプト、ゲームプログラム。
  FPLAY.COM    必須   オリジナルの音楽ドライバー。
  SONG.DAT     必須   音楽と効果音のデータ。
  RBRANK.DAT   任意   オリジナルのハイスコア・設定ファイル。

ディスクには SGC.COM、READJS.COM、RUDEBR.BAT もありますが、これらは
読み込まず、必要ありません。BIOS、フォントROM、音源ROMも不要です。
音楽はYM2203のエミュレーションで鳴らしており、ROMを必要としません。

ファイルの用意のしかたは2通りあります：

  1. ファイルをそのまま置く。SGM1.DAT、FPLAY.COM、SONG.DAT（以前の
     スコアを使いたい場合はRBRANK.DATも）を、ゲームのフォルダ（プログラム
     と同じ場所）か、その中の RUDEBR というサブフォルダにコピーします：

       Rude Breaker PC/
         rudebreaker.exe
         SDL2.dll
         SGM1.DAT
         FPLAY.COM
         SONG.DAT

     Linuxではファイル名を大文字で正確に一致させてください
     （sgm1.dat ではなく SGM1.DAT）。

  2. ディスクイメージを置く。ゲームのPC-98ディスクイメージを、そのまま
     ゲームのフォルダ（またはRUDEBRサブフォルダ）に置きます。対応形式：
     .hdm、.fdi、.d88、.hdi、.nhd、またはそれらを1つ収めた .zip。
     イメージ内のFATファイルシステムから直接読み込み、イメージ内の
     RUDEBRフォルダにも対応しています。ディスクへの展開は行いません。
     イメージが複数ある場合は、.hdm、.zip、.fdi、.d88、.hdi、.nhd の順に
     調べ、ファイルが揃っている最初のものを使います。

検索する場所と順番は次のとおりです。1と2で指定したフォルダや
イメージは、ファイルがなくても必ず使われます（その場合は下記の
ウィンドウが出ます）。3～5はファイルがある場合だけ使われ、どこにも
ない場合はプログラムのあるフォルダが表示されます：

  1. プログラムの引数で指定したフォルダまたはディスクイメージ。
     例：rudebreaker.exe D:\games\rudebr.hdm
  2. 環境変数 RUDEBR_ASSETS で指定したフォルダまたはイメージ。
  3. プログラムのあるフォルダ（まずファイル、次にディスクイメージ）。
  4. プログラムのあるフォルダ内の RUDEBR サブフォルダ。
  5. カレントフォルダの assets/raw/RUDEBR（開発者向け）。

必須ファイルが足りない場合、ゲームは起動しません。「disk files needed」
というウィンドウに、調べたフォルダまたはイメージと、各ファイルが
見つかったか（found）見つからないか（MISSING）が表示されます。足りない
ファイルを用意して、もう一度起動してください。RBRANK.DATだけがない
場合は、オリジナルのハイスコア表と初期設定で始まり、保存時にファイルが
作られます。

ゲームが作るファイル：

  RBRANK.DAT       オリジナルのセーブファイル：ハイスコア表とゲーム設定
                   （難易度とGAMEPLAYの各オプション）。ゲームファイルを
                   読み込んだフォルダ（ディスクイメージの場合はイメージと
                   同じフォルダ）に保存されます。削除するとスコアと設定が
                   初期化されます。
  rudebreaker.cfg  PC側の設定：パレット、ランク、トレーニング、キーと
                   パッドの割り当て。プログラムと同じフォルダに保存。
  rudebreaker.ini  フレーム進行の選択：pacing=smooth または pacing=exact。
  pace.txt         タイミングの簡単なレポート（7章）。削除しても
                   問題ありません。


3. 操作方法
-----------

キーボード（初期設定）：

  移動              方向キー、W A S D、テンキーの 8 4 6 2
  ショット / 決定   Z、スペース、テンキーの 0
  モード            X、N、M、Enter、テンキーのEnter
                    （サイドのオプションを攻撃型と防御型で切り替え）
  スペシャル        左右のShift
  スピード          C、左右のCtrl（下記参照）
  ポーズ / 戻る     Esc
  終了              F10
  フルスクリーン    F11（いつでも切り替え可能。FULLSCREEN
                    オプションと同じく保存されます）
  タイミング表示    F8（フレーム進行の情報を表示、7章）

ゲームパッド：

  一般的なPC用ゲームパッド（XInput・DirectInput）は自動で認識されます。
  ゲーム中に抜き差ししても構いません。

  移動              左スティックまたは十字キー
  ショット / 決定   下ボタン（XboxパッドのA）
  モード            右ボタン（B）
  スペシャル        左ボタン（X）
  スピード          上ボタン（Y）。標準配置でないパッドでは
                    ボタン4（4番目のボタン）。
  ポーズ            Start
  終了              Back / Select

SPEEDボタン：押すたびにプレイ中の自機の速度が、上がって下がってを
繰り返す順で切り替わります：

  LOW  ->  MID  ->  MAX  ->  MID  ->  LOW  ->  MID  ...

  LOW  低速
  MID  標準（初期設定）
  MAX  高速

上部のバーに現在の速度が SPD LOW、SPD MID、SPD MAX と表示されます。

各ゲームはGAMEPLAYで選んだMOVE SPEEDで始まります。ボタンでの変更は
そのゲームが終わるまで有効で、MOVE SPEEDの設定は変わりません。

ポーズ：Esc（またはStart）でのポーズはプレイ中のみです。タイトル、
デモ、メニューではポーズしません。メニューではEsc（キーボード）または
Bボタン（パッド）で1ページ戻ります。

ウィンドウの大きさは変更できます。画面はオリジナルの640x400の比率を
保ちます。


4. タイトル画面とCONFIGメニュー
-------------------------------

ロゴ、タイトル、ランキング表示、オープニングはオリジナルの画面です。
その前に無音のカードが流れます：粒子が飛んできてルードブレイカーの
ロゴになり、少し止まったあと、「30TH ANNIVERSARY EDITION」（白文字で
ロゴの幅いっぱいに広がり、着地すると一度やわらかく光ります）と
クレジットの行が下からせり上がります。全体で約2.5秒後にカードが
フェードアウトし、オリジナルのコンパイルのロゴと音楽が始まります。
どのキーやパッドのボタンでもカードを飛ばして、すぐにコンパイルの
ロゴへ進めます。SIDE PANELSがONのときは、ゲーム画面上部のスコア行を
左右に数ピクセル内側へ寄せ、パネルの枠で切れないようにしています。
タイトル画面には、ロゴの下中央に白い「30TH ANNIVERSARY EDITION」
（5秒ごとに文字のまわりがやわらかく光ります。左サイドパネルのロゴの
下でも同じ光が出ます）、10秒ごとに黄色と緑の間でなめらかに色が
変わるPUSH TRIGGER、そして (c) COMPILE 1996 と (c) SHMUPSBR 2026 の
クレジットが表示されます。
タイトルでショットを押すとゲーム開始、タイトルメニューからCONFIGを
開けます。
タイトルメニューの RETURN はゲームの最初（コンパイルのロゴ、デモ、
タイトル。オリジナルどおり）に戻り、EXIT はゲームを終了します。
メニューの行はタイトル画像の大きな (c) COMPILE 1996 の行に重なり
ますが、これはオリジナルどおりの配置です。

CONFIGには次のページがあります：

GAMEPLAY

  項目は空行をはさまずに続けて並び、順番は DIFFICULTY、SUICIDE
  BULLETS、SHIP SELECT、MOVE SPEED、PALETTE、TRAINING、FRAME
  PACING、RANK、SIDE PANELS、BULLET COLOR、HITBOX、LOOP、FULLSCREEN、BACK です。

  DIFFICULTY       VERY EASY、EASY、NORMAL、HARD、VERY HARD。オリジナル
                   そのままの難易度です。NORMALがオリジナルの初期設定。
                   RBRANK.DATに保存されます。

  SUICIDE BULLETS  ON：敵が破壊されたときに撃ち返し弾を出します
                   （オリジナルのオプションと同じ）。OFF：出しません。

  SHIP SELECT      オリジナルの同名オプション。武器の扱いを決めます：
                   ON：最初に「PLEASE SELECT YOUR OPTION」画面で武器を
                   1つ（VULCAN、LASER、MISSILE）選びます。以後の武器
                   カプセルはすべてその武器になり、ゲーム中ずっと
                   その武器のままです。
                   OFF（初期設定）：選択はありません。カプセルはV・L・M
                   の3種類が出て、別の文字のカプセルを取るとプレイ中に
                   武器が変わります。

  MOVE SPEED       LOW、MID（初期設定）、MAX。オリジナルと同じ自機の
                   移動速度。各ゲームはこの速度で始まります。

  RANK             ON（初期設定）：プレイ内容によって敵弾が速くも遅くも
                   なります（6章）。OFF：弾速はオリジナルどおり固定。

  BULLET COLOR     PINK（初期設定）、LILAC、BLUE、GREEN、ORIGINAL。
                   破壊できない敵弾を、元の色（赤・オレンジ・金）に
                   関係なくすべて塗り替えます。ボスのレーザーも
                   ケイブ風に全長を塗り替えます。暗い縁、本体、明るい
                   芯の陰影はそのままです。ゲームはこれらの弾を色では
                   なくオブジェクトの種類で区別しています：敵弾には
                   弾のビットがあり、「撃ち落とせる」ビットがありません。
                   撃ち落とせる弾、敵、アイテム、自機のショットは元の色の
                   まま。弾を撃ち落としたあとに残る無害な火の玉も同じです。
                   ORIGINALはすべての弾をゲームのままにします。

  PALETTE          MODERN（初期設定）：Filipeによるゲームの色の
                   再調整。ORIGINAL：PC-98の色。

  TRAINING         ON：練習モード（5章）。OFF：通常のゲーム。

  FRAME PACING     SMOOTH または EXACT（7章）。

  SIDE PANELS      ON（初期設定）：16:9のウィンドウか全画面では、
                   ゲーム画面を中央に置き、左右に情報パネルを表示します：
                   ランクのグラフ、装備、残機、無敵時間、速度、スコア、
                   撃墜率、勲章、レベル、時間、NO DEATH、入力を表示する
                   アーケードスティック。ロゴと横のアートは、お手持ちの
                   データのタイトル画面から取り出しています。
                   OFF、または4:3 / 16:10のウィンドウ：従来の見た目。
                   LOADOUT（装備）は2つのレベルを、1レベル1ブロックで
                   表示します（レベル1も含み、最初のブロックが埋まります）。
                   SHOTはメインショット：4段階なので4ブロック。レベル2、
                   3、4（MAX）はパワーアップアイテム2個、10個、18個で
                   上がり、ブロックはアイテム1個ごとに埋まっていきます。
                   ミスすると1段階下がります。V / M / L のサブウェポンは
                   それぞれ3段階で3ブロック。持っている武器と同じ
                   カプセルを取ると1段階上がり、MAXではカプセルが1000点に
                   なります。別の色のカプセルは、レベルを保ったまま武器を
                   変えます。サブウェポンを持っているときに被弾すると、
                   残機の代わりにサブウェポンを失います。そのときは
                   NO SUB と空のカプセル枠が表示されます。EXTENDS は自機と
                   残機の数を表示します。
                   I-FRAMES は無敵時間を円グラフで表示します：付与された
                   ときは塗りつぶした円、減るにつれて12時の位置から時計回りに
                   扇形が開き、なくなると薄い円の輪郭だけになります。
                   黄色：パワーアップアイテムまたはカプセル。紫：被弾後
                   または復活後。
                   ランクのグラフでは、ミスするたびにドクロが付きます。
                   グラフは直近60秒を表示してスクロールし、古いデータが
                   左へ消えていきます。各ステージの開始時にグラフは
                   消去されます（ランク自体は消えません）。
                   RANK OFF（またはトレーニング中）は、グラフ枠に
                   RANK SYSTEM / OFFLINE と表示され、15秒ごとにCRT風の
                   走査線がゆっくり上っていきます。ランクの数値は
                   「/ 159  OFF」になります。
                   ランクはステージをまたいで引き継がれ、新しいゲームで
                   だけリセットされます。横の小さな「x1.05」は現在の
                   ランク上昇倍率です。
                   この配置では、ゲーム画面をPC-98のモニターと同じ4:3
                   （ピクセルが横より1.2倍縦長）で表示します。従来の
                   見た目は正方形ピクセルです。
                   HIT COUNT は、そのステージで倒した敵の数 / ステージの
                   固定の敵数を表示します（ステージ1～5で369、315、128、
                   205、46：各ステージ自体が配置する敵。無限に湧く敵、
                   弾を出す発生源、ランクやタイミングで増える敵は数えず、
                   弾、アイテム、隠しポイントも含みません）。HIT RATIO は
                   同じ値を百分率とバーで表示します。ミスするとステージの
                   一部をやり直しますが、数は合計を超えません。
                   MEDALS は、各ステージ（1～5）に10個ずつ隠された勲章の
                   うち、そのステージで取った数を表示します。ゲーム自身の
                   勲章カウンターをそのまま使っており、出現した勲章を
                   取ったときだけ増え、ステージごとに0に戻ります。
                   NO DEATH は、ミスするまでは YES、ミスすると NO を
                   表示します（回数は表示しません）。全5ステージと
                   コンティニューを通して NO のままで、新しいゲームを
                   始めたときだけ YES に戻ります。トレーニング中は枠の
                   見出しに TRAINING も表示されます。
                   LOOP ON で2周目以降は、RANK 枠の見出しに周回数も
                   表示されます：LOOP 2、LOOP 3 …。1周目と LOOP OFF
                   では表示されません。

  HITBOX           OFF（初期設定）、PINK、LILAC、BLUE、GREEN、RED、
                   WHITE。自機の上に、実際の当たり判定（12×18ピクセル）
                   と同じ大きさの点を表示します。点の色は敵弾の色と
                   同じにはなりません：その色は飛ばされ、BULLET COLOR
                   を当たり判定の色に変えると、当たり判定は次の色に
                   進みます。BULLET COLOR が ORIGINAL のとき RED は
                   飛ばされます（オリジナルの弾は赤のため）。
                   rudebreaker.cfg に保存されます。

  LOOP             OFF（初期設定）：オリジナルどおり、ステージ5の後に
                   エンディングで終わります。ON：ステージ5をクリアすると
                   2周目としてステージ1から再開し、その後も3周目と続き
                   ます。スコア、残機、武器はそのまま引き継がれます。
                   周回ごとに難しくなります（6章を参照）。
                   rudebreaker.cfg に保存されます。

  FULLSCREEN       OFF（初期設定）または ON。ゲームの縦横比を保った
                   まま画面全体に表示し（横長の画面では SIDE PANELS
                   が左右を埋めます）、マウスポインタを隠します。
                   F11 でいつでも切り替えられます。
                   rudebreaker.cfg に保存されます。

  BACK

                   左右で切り替えます。
  DEFINE KEYS      UP、DOWN、LEFT、RIGHT、FIRE、MODE、SHIFT、PAUSE、
                   SPEED を割り当て直します。動作を選んで、新しいキーか

  PLAY / PAUSE / STOP   プレイヤーの操作。

5. トレーニングモード
---------------------

TRAINING は練習用です：

  - 自機は被弾しません。武器も残機も失いません。
  - 隠し勲章のポイントが、その場でずっと赤く点滅します。普段は撃って
    いるときにだけ見える赤い点滅と同じもので、場所を覚えられます。
    勲章を出すには通常どおりポイントを撃ち続ける必要があり、スコアも
    変わりません。
  - RANKは使われず、難易度はDIFFICULTYの設定のままです。
  - トレーニングでのスコアはハイスコア表に載らず、そのプレイの内容は
    RBRANK.DATに保存されません。

通常どおり遊ぶときは TRAINING をOFFにしてください。


6. スコア・セーブ・オリジナルの隠し要素
---------------------------------------

ハイスコアと設定は、オリジナルの形式でRBRANK.DATに保存されます。
新しいスコアは名前を入力したときに保存されます。

難易度とゲームのルールはすべてオリジナルどおりです。

RANK（GAMEPLAYのオプション、初期設定はON）は、ザナックのランク
システムを参考にしたこの移植版独自の要素です。内部のランク値は、
生き残っている間と得点したときに上がり、ミスするとリセットされます
（下記参照）。上昇の速さはこの移植版の以前のバージョンの3分の1で、
そこにゲームの進行とともに大きくなる倍率がかかります：メインショットの
レベルが1つ上がるごとに+1%、サブウェポンのレベルが1つ上がるごとに+5%
（1000点になるだけのカプセルや、色が変わるだけのカプセルは数えません）、
スコアエクステンドで残機が1つ増えるごとに+5%。倍率は新しいゲームの
たびにx1.00から始まり、ミス時のリセットやDIFFICULTYによる上限は
変わりません。
サブウェポンを失う（被弾してメインショットだけになる）と、現在の
ランクの3分の1が下がります。下がった分は記憶され、サブウェポンを
取り直すと戻ります（DIFFICULTYの上限は超えません）。新しいゲームで
消去されます。ランクが高いほど敵弾が速くなり、これはDIFFICULTYを
上げたときと同じ仕組みです。ほかは何も変わらず、ボーナスは選んだ
DIFFICULTYのままです。DIFFICULTYは開始点と下限を決めます：ランクに
よって、選んだ難易度より弾が遅くなることはありません。VERY EASYと
EASYではランクは半分までしか上がらず、HARDとVERY HARDでは半分から
始まります。ランクは新しいゲームのたびにリセットされます。

プレイ中の難易度でランクが最大になると、難易度が1段階上がり、ランクは
その難易度の開始点からやり直しになります。これは選んだDIFFICULTYの
上限まで続きます：

  VERY EASY  -> NORMALまで（EASYを経由）
  EASY       -> HARDまで（NORMALを経由）
  NORMAL     -> HARDまで
  HARD       -> VERY HARDまで
  VERY HARD  -> VERY HARDのまま

上限ではランクは最大のままです。難易度が上がるたびに、サイドパネルの
LEVEL枠が2秒間点滅し、RANKのグラフのその時点に上向き矢印付きの緑の
線が入ります（ミスはドクロ）。また、ゲーム本来の1000点ボーナスが入り、
自機の上に 1,000 の表示が出ます。

NORMALまたはVERY HARDを選んだ場合、上限に達してランクが最大のときは、
プレイ20秒ごとに敵弾が1%ずつ速くなり、最大+25%になります。LEVEL枠に
表示されます（例：V.HARD +3%、HARD +3%）。被弾（サブウェポンを失う）
またはミスで+0%に戻ります。

ミスすると、選んだDIFFICULTYとその開始ランクに戻ります。難易度の
上昇で変わるのはランクが変えるもの（敵弾の速さとランクの範囲）だけ
で、スコア、ボーナスなどはすべて選んだDIFFICULTYのままで、保存された
設定も変わりません。トレーニング中は無効です。RANK OFFではオリジナルと
まったく同じで、難易度の上昇も弾の加速も+1000ボーナスもなく、
サイドパネルのランクのグラフには RANK SYSTEM / OFFLINE と表示されます。

LOOP（GAMEPLAYの項目、初期設定はOFF）はこの移植版で追加された機能
です。LOOP ON では、ステージ5をクリアしてもエンディングにならず、
2周目としてステージ1から再開し、その後も3周目と続きます。スコア、
残機、武器は引き継がれます。新しい周回ごとに：

  - 基本難易度が前の周より1段階上がります。出発点は選んだ
    DIFFICULTY です（VERY EASY → EASY → NORMAL → HARD → VERY
    HARD）。VERY HARD に達するとそのままで、下の周回倍率だけが
    上がり続けます。新しい難易度（ゲーム自身のその難易度の敵弾と
    敵の耐久力の設定）は、その周のステージ1の開始時から有効です。
  - ランクは新しい基本難易度の開始値からやり直しです。難易度上昇の
    上限、ランクの範囲、上限での弾の加速は、1周目で選んだ
    DIFFICULTY に従うのと同じように基本難易度に従います（例：
    NORMAL のゲームは2周目で HARD になり、そこから VERY HARD まで
    上がれます）。
  - ランクで決まる値はすべて周回数倍になります：1周目は×1、
    2周目は×2、3周目は×3…。対象はランクの上がる速さ、ランクが
    敵弾の速さに加える量、上限での加速の+1%の刻みです。上限：倍率は
    ×8で止まり（8周目以降）、敵弾の速さはゲーム自身の VERY HARD の
    値を超えず、上限での加速は+25%×倍率までですが+50%を超えません。
  - ミスすると、その周の基本難易度とその開始ランクに戻ります。
  - 2周目からは、サイドパネルの RANK 枠の見出しに周回数を表示します
    （LOOP 2、LOOP 3 …）。1周目は表示されません。カウントは99で
    止まります。
  - ゲームオーバーで終了し、新しいゲームは選んだ DIFFICULTY で
    1周目から始まります。
  - トレーニング中も LOOP ON ならステージ5の後にステージ1から
    再開しますが、難易度と倍率は変わりません。

LOOP OFF では、オリジナルとまったく同じくステージ5の後に終わります。

オリジナルのデバッグ用隠しコマンドもコードに残っています。プレイ中に
Escでポーズし、N E K O C O と入力します。その後：

  2   無敵の切り替え
  3   デバッグ表示の切り替え
  1   押している間、フレーム待ちなしで動作（早送り）
  4   エンディングへ移動

オリジナルの隠し機能で、手を加えていません。


7. フレーム進行と垂直同期
-------------------------

オリジナルのゲームロジックは毎秒約30.67フレームで動きます。どのPCでも
この速度を保つので、オリジナルより速くなることはありません。

グラフィックドライバーが対応していれば、モニターの更新（垂直同期）に
合わせます：

  SMOOTH（初期設定）  60、120、240Hzのモニターでは、ゲームの1フレームを
                      ちょうど2、4、8回の更新で表示します。動きは完全に
                      均一です。このときゲームは毎秒30.00フレームとなり、
                      オリジナルより約2%遅くなりますが、気付かない程度です。

  EXACT               ゲームを正確に毎秒30.67フレームで動かし、更新の
                      たびに最新のフレームを表示します。60Hzの画面では
                      動きにわずかな周期的なムラが出ます。

ほかのリフレッシュレート（75、144、165Hzなど）では常にEXACTになります。
垂直同期が使えない場合は、タイマーで30.67に合わせます。

F8で、モード、測定したリフレッシュレート、タイミングの統計を小さく
重ねて表示します。同じ情報は、起動時と終了時にプログラムと同じ
フォルダの pace.txt に書き出されます。動きの滑らかさの問題を報告する
ときに役立ちます。


8. 意図的に外したオリジナルのオプション
---------------------------------------

オリジナルのオプションメニューにあった次の項目は、この移植版では
表示しません：

  AUTO SHOT、WAIT、PRIORITY、FRAME SKIP、SWAP KEYS

これらはPC-98のハードウェアの速度や制限を補うためのもの、またはPCの
操作設定で代わりになるものです。最近のPCなら処理落ちもコマ落ちもなく
フルスピードで動き、速度は移植版のフレーム進行（7章）で固定され、
キーの入れ替えはDEFINE KEYSで行えます。オリジナルの INVINCIBLE と
NAME ENTRY の項目は TRAINING に置き換えています。


9. 既知の制限
-------------

  - 垂直同期とSMOOTHのフレーム進行は、まだすべてのモニターと
    グラフィックカードで試してはいません。動きが滑らかでない場合は
    EXACTを試し、pace.txtを送ってください。
  - これはテスト版です。オリジナルと見た目や音が違うところがあれば
    お知らせください。


10. 不具合の報告
----------------

見た目、音、操作感がおかしいときは、次の情報を送ってください：

  1. 何が起きたか、本来どうなるはずだったか。
  2. 再現手順（ステージ、モード、メニュー、押したボタン）。毎回
     起きるか、ときどきかも。
  3. できればスクリーンショットか短い動画。
  4. WindowsまたはLinuxのバージョン、グラフィックカード、モニターの
     リフレッシュレート、使っているコントローラー（キーボードか、
     どのゲームパッドか）。
  5. PACINGの設定（SMOOTHかEXACT）と、ゲームフォルダの pace.txt
     （終了するたびに書き直されるので、問題が起きた直後にコピー
     してください）。
  6. ビルド名：Rude Breaker 30th AE pr9ze。
